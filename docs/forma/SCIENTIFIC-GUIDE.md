# 科研图表使用说明

FORMA 当前有 144 个图库模板。可以按用途、图型家族、关键词和收藏筛选；统计分布、过程监控和预测相关模板也可在图库中找到。图库模板与连续变形图型分别计数，以当前图库筛选统计和编辑器兼容性提示为准。

默认数据均为确定性合成演示，没有真实研究对象、实验发现或临床结论。模板的结构校验负责字段、数值与图形编码的一致性；研究设计、样本独立性、分析方法和来源真实性仍需由实际研究确认。

## 选择输入方式

| 输入 | 模板 | 图中处理 |
| --- | --- | --- |
| 独立原始观测 | 原始散点误差、配对散点、回归、一致性分析、残差、剂量响应 | 保留观测，按明确公式计算均值、SD、OLS 或差值 |
| 二分类标签与得分 | ROC、PR、校准曲线 | 同一测试集；正类为 1；得分越大越可能为正类 |
| 训练记录 | 学习曲线 | 训练/验证共用损失尺度，null 留断点 |
| 已计算的分析结果 | 森林、火山、MA、PCA、碎石、富集、曼哈顿、研究漏斗 | 接收效应、区间、p 值、主成分或特征值，不代替上游统计分析 |
| 明确汇总计数 | 混淆矩阵、UpSet | 校验完整矩阵或排他交集，保留零和集合语义 |

编辑页的圆圈问号依次介绍科研图型、适用场景、字段与统计量含义。「Agent 制作」提供制作说明书和可离线使用的原版 HTML 代码；把它们与自己的数据交给 Agent，直接生成图表成品。Agent 教程见 [使用 Agent](AGENT-GUIDE.md)。

作品编辑器右侧的字段说明与真实表格来自同一份字段定义。通过「导入表格」导入 CSV / TSV 或粘贴 Excel / WPS 区域时，先确认原列与图表字段的对应；原表头和未映射列会保留。直接在表格中粘贴矩形区域，只覆盖从当前单元格开始的相应区域；批量操作支持撤销。

错误数据保留在表格里，图表暂时显示上一次有效数据；点击「定位单元格」或「下一个问题」逐项核对。日期按字段指定的 YYYY-MM 或 YYYY-MM-DD 填写，不存在的日期不会自动顺延。甘特图的结束日不计入时长，结束日期必须晚于开始日期。区间上下界和日期顺序错误会定位相关单元格，不自动排序、删行或把缺失值补成 0。

染色体长度、集合名称、解释方差、分箱数和剂量单位等文档级参数可在「来源与图表参数」中核对。CSV 只携带记录字段；需要交换这些参数时，应使用完整 JSON、作品文件或制作说明书，并先处理未完成的表格修改。

已接入的科研原始点、柱和区间标记支持图表与表格互相定位。例如 UpSet 和富集图即使按数值排序，也会定位原表的对应记录；修改数值后仍保留其记录 ID。

在作品编辑器的箱线、小提琴、雨云、均值与标准差视图中，点击统计摘要可以查看参与计算的原始行。回归拟合与均值置信带同样关联其输入观测。关联栏位于表格上方，显示记录数量和实际行号，可以跨页逐条查看，也可通过「复制关联行」复制这些记录及原表头。鼠标经过表格行时，对应原始点和统计摘要一起高亮。关联范围按持久记录 ID 查找，数值修改、删行与撤销后会更新；不会因为行交错排列而包含无关记录。

关联高亮用于核对统计来源，矩形选区用于批量编辑，两者分别操作。关闭关联栏不会删除数据；切换步骤时清除当前关联状态。ROC 阈值、相关矩阵等其他汇总对象尚未接入这组操作，不能把汇总形状等同于某一条原始记录。

## 统计口径

- **均值误差图、剂量响应**：误差棒为样本均值 ± 样本标准差，SD 分母为 n−1；原始观测全部保留。没有把 SD 当成均值置信区间。剂量为对数尺度，零剂量不直接放上对数轴；均值连线不是 4PL 拟合，不提供 IC50。
- **回归**：含截距的一元 OLS。置信带为逐点均值响应的 95% 区间，标准误乘以 t(n−2) 临界值；不是个体预测区间或同时置信带。要求独立、线性、同方差与近似正态误差。常量响应的 R² 显示「未定义」。
- **一致性分析**：横轴 (A+B)/2，纵轴 A−B。平均差为偏倚，一致性界限为偏倚 ± 1.96×差值样本 SD，未计算界限本身的置信区间。假设差值近似正态、方差稳定且配对独立。
- **森林图**：对数轴展示已输入的比值效应与置信区间，参考线为 1。标记等大，n 仅为样本量，不冒充研究权重；不自动合并效应。
- **ROC**：并列得分共同进入阈值，按 ROC 线段梯形积分计算 AUC。
- **PR**：AP = Σ(召回率增量 × 当前阈值精确率)，采用阶梯展示，未使用梯形积分替代 AP。虚线为评估集正类比例。AUC 与 AP 均没有未经计算的置信区间。
- **校准**：等宽概率分箱，左闭右开，最后一箱包含 1。横轴是箱内平均预测概率，纵轴是箱内正类比例，空箱保留断点。分箱 n 保留在提示中，没有为稀疏分箱生成虚构置信带。
- **火山、MA、富集**：`padj` 必须是外部分析得到的多重检验校正 p 值，范围 (0,1]。缺失和数值下溢为 0 的结果需在上游处理，不能静默补一个很小的 p 值。阈值只是当前文档的设置。
- **PCA**：输入计算完成的得分和解释方差百分比，保持两轴得分单位的等比例显示。不同标记形状区分组别；不由组名生成椭圆、p 值或分类结论。
- **碎石图**：需提供全部主成分特征值，按降序排列，解释度以其总和为分母。仅输入截断的前几个值会改变分母，不能冒充总解释度。
- **富集气泡**：GeneRatio=count/total，面积编码命中数，色深编码 −log₁₀ padj。数值定义和色阶均显示；total 需明确为该次分析输入基因总数。
- **混淆矩阵**：行是真实类别，列是预测类别，色深和主数字编码原始计数；提示含行内百分比。需要完整方阵，零计数需显式输入。
- **UpSet**：每列表示恰好属于标出的集合、不属于其余声明集合的排他交集。一个元素只计入一列；输入交集之外的元素不计入图中总量。
- **曼哈顿图**：输入已完成关联检验的 p 值。按指定染色体长度和真实 bp 坐标定位，染色体间留间隔；阈值由文档指定，不推荐一个适用于所有研究的阈值。
- **研究漏斗**：输入效应与 SE，纵轴倒置。边界为输入参考效应 ± 1.96 SE，不自动计算合并效应，也不把不对称解释成已证实的发表偏倚。

## 动效与输出

所有新图支持入场、展开、重播、暂停、时间轴任意定位；反向定位后可确定性恢复最终帧。颜色用于分组或明确的数值编码，空心/实心标记、形状和虚实线提供冗余区分。默认使用纸白和中性色谱。

作品编辑器可以把图表组成有顺序的多步作品。明确关联、记录身份和观测含义一致的数据，才适合连续变形；其他步骤仍可正常切换并播放图表入场。图库模板与编辑器变形图型使用不同计数，具体兼容范围以编辑器提示为准，不代表任意数据、任意两图之间都适合变形。

静态 SVG / PNG 用于文档，互动 HTML 保留作品数据、完整引擎与播放控制，MP4 用于视频。需要精确保留网站效果时，把导出的 HTML 与制作说明书一起交给 Agent。每步的单位、来源、置信区间或密度含义应单独核对；沿用数据后再次修改来源步骤，需要显式「同步数据」才会更新关联步骤。

## 核对资料

这些资料用于核对方法定义与图形语义；图表实现独立编写。

- [Penn State STAT 501：均值响应置信区间](https://online.stat.psu.edu/stat501/lesson/7/7.1)：t 临界值、均值响应标准误及适用假设。
- [NIST：Bland–Altman 图](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/blandalt.htm)：均值/差值坐标、偏倚、近似一致性界限与分布假设。NIST 页面使用约 ±2 SD，本实现明确标注常用正态近似 ±1.96 SD。
- [scikit-learn：Average Precision](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html)、[Precision–Recall](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.precision_recall_curve.html)、[ROC AUC](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_auc_score.html)、[概率校准](https://scikit-learn.org/stable/modules/calibration.html)：得分阈值、AP 定义、概率与观测频率的区分。
- [Bioconductor：DESeq2 工作流](https://bioconductor.org/packages/release/bioc/vignettes/DESeq2/inst/doc/DESeq2.html)：差异表达分析结果和主成分图的上游分析语义。
- [UpSet 原项目](https://upset.app/)：交集柱与成员矩阵布局。方法来源：Lex 等，2014，doi:10.1109/TVCG.2014.2346248。

统计摘要的对应以参与计算的原始记录 ID 为依据。整组改名或重排时，箱线、密度和均值摘要保持对应；改动分组成员后，统计总体已变化，不会仅凭名称相同把两个摘要当作同一对象。样本分组颜色在同一作品的相关步骤中随这组记录保留。当前尚不支持跨作品的独立分组、模型和变量身份管理。
