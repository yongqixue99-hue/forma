# 让 Agent 使用 FORMA

网站：https://forma.ovocode.xyz/
使用指南：https://forma.ovocode.xyz/#guide

请使用浏览器操作 FORMA，把我提供的数据做成动态图表作品，并交付导出的文件。如果缺少数据或要比较的问题，先向我确认。不要编造数值、来源、置信区间或分析结论。

## 1. 选择起点

打开 FORMA。首屏是产品介绍，向下滚动可以查看整屏案例。选择收入结构、经济增长或企鹅分布，点击「编辑这个案例」进入编辑器；也可以到「图表库」选单图，或在「变形预览」选择「使用此预设」。示例数据只是起点；如果我提供了数据，需要替换。

通过浏览器工具操作页面上的控件，不要修改浏览器存储或未公开的内部状态。首次打开默认为英语，可以在右上角切换中文；语言切换不会翻译我填写的标题和原始数据。

每张图详情中都有「推荐使用场景」，说明它回答的问题、选择依据与相近图型。导入前先检查。可按任务读取 https://forma.ovocode.xyz/forma/chart-recommendations.json，再读取选中图的完整要求。「使用指南 → 交给你的 Agent」提供可安装的 FORMA skill。

## 2. 导入并核对数据

在编辑器选择当前步骤，打开「数据 → 导入表格」。支持 XLSX、CSV、TSV 和粘贴单元格。选择工作表与范围，核对表头，把原列对应到图表字段，检查预览后再应用。「原表 / 字段」可以查看保留的原始列。数据表旁的问号说明当前图型的字段、用途和容量。

- 保留原值、单位、日期、缺失观测和来源。空白不等于零。
- 对照原表检查行数、负值、百分比和类别名称。不能为了塞进图表而删除记录；换用合适图型，或先征得我同意再汇总。
- Excel 公式只读取文件中已保存的值，网站不会重新计算公式。
- 地图使用完整国家名称或 ISO 代码，例如 Germany / DE / DEU。输入前缀有多个候选时，从建议列表选择；单个首字母不能唯一确定一个国家。
- XLSX 文件最多 8 MB，文本最多 2 MB；选区最多 1,501 行（含表头）、32 列。遇到限制时和我说明，不要截断数据。

应用后检查图表标题、单位、数值正负、标签和来源。表格修改与粘贴可以撤销。输入有误时会保留上一次有效图表，不要把旧画面误认为本次修改成功。

## 3. 组织作品

通过「添加下一步 → 沿用当前数据」为同一批记录选择兼容图型。每一步保留独立副本；修改数据后，用「同步数据」核对受影响步骤，再应用到选定范围。

图型要符合数据含义：占比图需要可相加的非负整体，增速不能相加；只有对应观测且含义兼容的数据才适合连续变形。无关数据用完整场景切换。变形中间的形状不是新增观测。

选中步骤后编辑标题和「样式」，用「标注」添加简短说明或绑定记录的标记。应用标注后检查它是否遮挡图表。统一配色，保证标签清楚，并采用我需要的画幅。

## 4. 调整节奏并完整播放

点击「预览 → 播放全部」，从头检查入场、过渡和静态停留。拖红色进度点可以跳转；拖动对应时间轴片段上的小把手，可以向左缩短、向右延长静态停留，浮层显示秒数。停留范围为 0.5–12 秒，把手也支持方向键。

预览速度为 0.5×、1×、2×、3×，只改变预览中的演变速度，停留仍按实际秒数播放，也不改写导出的节奏。要修改保存的动画时长，在「节奏」或相邻步骤的「过渡」设置中调整，改完后重新完整播放。尊重系统的「减少动态效果」偏好，不要擅自关闭。

## 5. 保存并交付

点击「保存作品」。作品保存在当前网站地址的当前浏览器中，没有账户云同步。换设备、浏览器或网站地址前，下载可编辑作品文件。「我的作品 → 恢复备份」用于重新打开文件；先核对预览，再恢复为副本。不要为了完成任务清空存储或覆盖其他作品。

按使用场景选择格式：

| 使用场景 | 操作 |
| --- | --- |
| PowerPoint、Word 中的静态图 | 打开「复制提示词」旁的下拉菜单，选择「复制图片」后到目标软件粘贴，或导出 PNG。这是图片，不是可编辑的 Office 图表。 |
| PowerPoint 演示文稿 | 单图详情或作品编辑器中选「导出 → PowerPoint · PPTX」，可选静态图表或内嵌动画。多步作品静态导出为每步一张幻灯片。 |
| 单独的动画视频 | 导出 MP4，再用「插入 → 视频」选择下载文件。复制图片不能携带动画。 |
| 浏览器中的交互播放 | 导出互动 HTML，打开下载文件检查播放。 |
| 矢量排版 | 导出 SVG。复制的 SVG 代码不能保证在 Office 中直接粘贴成图。 |
| 回到 FORMA 继续编辑 | 导出可编辑作品 JSON。 |

交付前，对照原表检查导出物中的数值、标签、单位、来源、缺失值和标注；动画还要检查开头、过渡和结尾。说明实际交付的文件，以及哪些环节没有验证。没有检查成功，就不要声称下载或粘贴已完成。

## 交给编程 Agent 继续修改

图表和编辑器的主复制按钮都是「复制提示词」，其中包含当前数据、样式、步骤、节奏，以及调用固定版本原版播放器的完整 HTML 模板。复制后连同自己的 Excel 表交给 Agent，由它替换数据并沿用原版播放器，不需要另附互动 HTML。提示词会要求 Agent 下载原版播放器并随成品交付，供离线使用。

本教程说明如何操作网站，不包含我的当前作品，也不代表允许分享它。FORMA 不会自动调用模型 API，也不会自动把表格发送给 Agent。


## 结构化配置与重复报告

「使用指南 → 打开 Agent 配置」可粘贴或导入 v1 请求、作品 JSON，校验后创建独立作品。接口和离线工具文档：https://forma.ovocode.xyz/forma/agent-api.md 。使用公开接口或可见控件，不直接修改浏览器存储。

更新一期报告时，点击编辑器「制作下一期」，导入新表，选择稳定 ID 或唯一对象字段，核对对象、单位和标注变化，再创建新报告，原报告保留。「导出 → PowerPoint」可下载每步一张静态图片幻灯片，或嵌入整段动画。修改图表数据仍需保留可编辑作品 JSON。
